# PC File Transfer — product website

Static GitHub Pages site for RD Apps Studio. Includes `index.html` and the `assets/` folder.

## Publishing
1. Create a public repository named `pc-file-transfer` under `rdappsdev-sys`.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)`.
4. The website will be available at `https://rdappsdev-sys.github.io/pc-file-transfer/` once GitHub Pages deploys.

## Before launch
- Replace the three **Coming soon** spans in `index.html` with real links to Google Play and GitHub Release assets. Do not publish placeholder download links.
- Confirm Android, Windows, and Linux compatibility statements for the public release.
- Add the product-specific Privacy Policy URL once finalized.
- The banner is promotional artwork; the screenshots section uses actual supplied screenshots.
